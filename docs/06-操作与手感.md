# 06 · 操作与手感

> 核心规律：光枪的手感 = **"指哪打哪"零妥协 + 一个深度节奏输入**。前者是物理底线，后者是 30 年来唯一被反复验证的深度来源——攻/守/装填的三态循环。

## 1. 输入资产盘点

光枪游戏可用的输入面：

| 输入 | 物理形态 | 设计语义 | 街机先例 |
|---|---|---|---|
| **扳机** | 主输入 | 开火 | 全部 |
| **踏板**（可选外设） | 脚部二值输入（或 TC5 式左右双踏板） | 掩体/格挡/慢动作/逃脱——每作选一个语义并贯彻 | TC 掩体、Crisis Zone 举盾（1999 年先例，早于 Razing Storm）、VC3 慢动作、HotD4 逃脱（街机为踏板连踩，Wii 版为甩动） |
| **枪口动作** | 甩出屏幕/枪体倾斜/泵动 | 装填/特殊动作 | 离屏装填（CRT 世代通用）、HotD3 泵动、Wii 甩枪 |
| **侧键/按键** | 枪体侧键、D-pad | 装填替代、武器切换、菜单 | GunCon 侧键（TC PS1 踏板替代）、Ghost Squad 战术手势 |
| **绝对指向** | 枪即指针 | 瞄准+菜单指针+UI 交互 | Wii 指针 |

**规则**：
1. **核心循环建立在 ≤2 个高频输入上**（扳机+一个节奏输入）。输入面越宽，单输入的练习回报越低。
2. 踏板是可选外设：设计时把节奏输入做成**可映射**（踏板/按键/甩枪三选一），默认按键，识别到踏板则提示绑定。TC5 双踏板（左探/右探/藏三元掩体）是最新范式，无踏板玩家用双键位组合等价实现。
3. 全部输入可重映射——社区已有固定语言：甩枪换弹、侧键方向、踏板掩护（复古游戏生态已把"每玩家独立踏板映射"做成惯例），**沿用约定，不要发明新语言**。
4. **新动词必须替换或合并一个旧动词**：在输入预算（≤2 高频输入）之外加新动词时，必须替换/合并现有动词或降级为低频事件键——轨道射击的深度预算有限（Zombie Revenge 教训）。

## 2. 装填设计：装填即节拍器

装填的本质是**强制呼吸口**——把"输出暂停"包装成动作。判据：装填是否占用注意力、装填时机是否有决策。

| 范式 | 机制 | 风险回报 | 代表 |
|---|---|---|---|
| **离屏装填** | 枪口甩出屏幕自动装满 | 装填期失去战场跟踪（信息断供期） | Virtua Cop、HotD2（日后 Wii 轨射标配） |
| **踏板装填** | 进入掩体自动装满 | 防御与输出互斥，制度化风险回报 | Time Crisis（松开=弹匣补满，TC1/2 为 8 发） |
| **按键装填** | 按侧键/键位装填 | 决策最轻，适合无踏板玩家 | 家用版惯例、Ghost Squad |
| **泵动装填** | 物理泵动/大幅甩动 | 仪式感=枪的人设 | HotD3 霰弹枪（现代泵动外设延续此范式） |
| **空仓硬直** | 打空后被迫硬直补弹 | 弹匣余量成第二资源条 | HotD（空仓暴露挨打） |

**规则**：
1. 弹匣容量（街机基准 8–10 发，TC 系手枪为 8–9 发）是密度调参旋钮：容量越小，"全歼一波 vs 留弹备险"的分配决策越强。
2. **装填必须有决策**：自动装填+无空仓惩罚=玩家无脑扫射（反模式）；装填过苛（老 Operation Wolf 机枪过热判罚）=挫败而非紧张。
3. 推荐默认：**离屏装填为主（现代外设天然支持）+ 可切换按键装填**；恐怖题材可叠加空仓暴露压力。
4. **离屏装填触发几何**：判定"完全离开有效画面"而非"准星贴边"——要求指针离开边框带且停留 ≥150ms（迟滞防抖）；同时接受外设侧主动上报的离屏事件（部分现代光枪提供离屏键映射，事件优先于坐标推断）。准星贴边抖动、追踪丢失**不得**误判为装填——这是量产必出的 bug 点，需要专门测试。

## 3. 掩体与节奏循环（有踏板语义时）

TC 踏板三态（30 年最深度的单条机制，必须理解其博弈结构）：
- **踩下（暴露）**：可射击、可被打。
- **松开（掩体）**：对子弹无敌 + 自动装满——**但倒计时照常流逝**。
- 由此产生"射 5 发留 1 发、提前 0.5 秒踩掩体"的微观博弈；防御是用时间付费的。

**规则**：
1. 若不做踏板，必须提供等价的**节奏器**：Wii 式甩枪装填（Overkill：'a visceral shake'）、按键掩护、或 Sin and Punishment 式闪避——没有节奏器的光枪游戏，难度只能靠密度与缩计时器硬顶，即玩家口中的"虚假难度"。
2. 踏板语义全作统一（一个词：掩体就是掩体）；多语义（格挡+掩护）需要 UI 永久提示。
3. 核心循环压在机械件上是单点故障（TC5 踏板偶发无响应被吐槽）——**按键永远是官方并行方案**。

## 4. "指哪打哪"：手感管线标准

中文社区对"光枪味"的定义线（B 站 181 赞："不是指哪打哪就没意思了"）。设计标准：

1. **当帧命中判定**：输入采样帧内完成碰撞检测与反馈提交，禁止隔帧。命中点=准星视觉中心，误差 ≤1 个准星半径（全屏判定覆盖自动化测试纳入 CI，见 `15` 坑 2）。
2. **每枪一条独立绝对坐标流**：多枪时不得依赖运行环境的单一合并光标抽象——每支枪的坐标与扳机必须**按设备配对**成独立流（坐标流与扳机流分别读数、同源绑定）；单人单枪时合并光标才可用。输入抽象契约与实现路线见 `14-输入抽象与跨硬件设计.md`。
3. **延迟预算（分段管理）**：总预算由三段和推导——①设备→游戏（外设侧，因方案而异，以实测为准）；②游戏当帧处理（目标 ≤1 帧）；③显示扫描出（10–40ms，取决于显示设备）。游戏侧只优化②，管线与测量的工程细节归 `14`；设计侧的硬性规则是：**所有前摇/反应窗用绝对时间（毫秒）计时而非帧数**（高刷下窗口不得变形）、公布测量方法学（高速相机拍摄 input-to-present）以经受社区实测、内置延迟监视器（原始坐标/丢帧/输入更新率/延迟显示，见 `14`）。
4. **准星渲染开关**：高精度方案的高手玩家要求隐藏准星的"街机原教旨"模式；精度余量小的方案需要游戏渲染准星。**两者都做，默认开准星**（详见 `13-UI与HUD.md`）。
5. **瞄准辅助的正确做法**：不做准星磁吸（伤害"指哪打哪"信任），准星也**永远不做平滑滤波**（伤 1:1 信任）——手持抖动用判定盒宽容度吸收（摄像头追踪方案固有抖动的正解）。辅助做在**判定盒宽容度**（街机传统：大判定盒）与 hit flash 确认上。Ghost Squad 的"藏准星盲打加分"是高手向选项，值得保留。
6. **扳机信号卫生**：廉价枪扳机去抖（合并 <30ms 内的重复触发）；高射速武器下一帧可能积压多个输入事件，须逐帧排水处理，而非每帧只取一个。
7. **射击事件后坐力友好**：见 `09-特效与打击反馈.md`。

## 5. 校准与设置体验（设计原则；工程实现见 `14`）

- **信任设备侧校准**：现代光枪普遍枪内校准（一次完成、随时可重做），游戏不强制冗长校准。游戏侧提供 **30 秒内完成的可选软校准**与实时追踪自检界面，认领界面直接内置靶场试射+实时追踪热力图——把校准页变成第一个"爽点"而不是设置项。
- **游玩距离与屏幕尺寸是真实跨度**：从桌面近距坐姿到客厅远距站姿都是合理场景——UI 字号、判定盒、准星可读性**按视角（目标角尺寸）定义而非像素**，参数按距离分档，靶场模式提供"校准你的站距"引导。
- 设置项最少清单：光枪灵敏度/死区、每玩家踏板映射、准星开关、降级输入选项（显示与输出配置的自愈逻辑见 `14`）。
- 多枪认领：**"每人朝屏幕开一枪认领归属"**的可视化认领界面——设备识别顺序不可依赖，可视化认领优于任何配置文件方案（按设备枚举与热插拔的工程要求见 `14`）。

## 6. 无枪降级方案（一等公民，不是兼容项）

Silent Scope PS2 版（无光枪支持=玩法尽失）与 Judge Dredd 家用版（丢枪体=丢游戏性）的双重教训：

- 鼠标模式：绝对定位天然兼容（光枪的位置流与鼠标同构），体验自然成立——**必须显式支持并作为一等公民宣传**。
- 手柄模式：右摇杆速度曲线单独调（光枪玩家与手柄玩家的瞄准速度预期不同），提供瞄准辅助选项。
- 陀螺仪模式：手柄+陀螺仪瞄准（右摇杆粗瞄+陀螺仪微调混合曲线）——掌机与体感手柄上的真实人群，最接近光枪的降级体验，成本极低、口碑回报高。
- 软件侧补偿"无枪体"损失：加重打击反馈栈（`09`）、加瞄准辅助、降低精度要求事件（人质事件减少）。
- 启动时检测输入设备：光枪在场则引导认领+试射间；不在场则平滑进入鼠标/手柄模式，不弹"检测不到光枪"的警告框。

## 7. 操作自检清单

- [ ] 扳机+1 个节奏输入构成核心循环？
- [ ] 装填有决策（非全自动无代价）？
- [ ] 当帧判定、无平滑、延迟分段预算达标且可监视（见 §4.3）？
- [ ] 准星渲染开关可用？
- [ ] 甩枪换弹/侧键/踏板约定兼容且可重映射？
- [ ] 30 秒内软校准+追踪自检，校准页是爽点？
- [ ] UI 可读性按视角定义，覆盖游玩距离跨度？
- [ ] 双人即插即玩（开枪认领）？
- [ ] 鼠标/手柄模式是完整体验而非残血版？

## 8. 反模式清单

- **把光枪当鼠标附属品**：HotD Remake（发售时光枪支持靠社区补丁）、Operation Wolf Returns（准星顶边够不着）、Until The Last Bullet（枪打不到全部区域）——Steam 差评案例三连。**原生支持必须是发布日状态。**
- **强制校准流程**：让玩家为进游戏先折腾 10 分钟（早期单点红外方案的世代痛点）。
- **准星磁吸辅助**：破坏绝对定位信任。
- **发明新装填语言**：玩家肌肉记忆已有约定，新语言=流失。
- **核心循环单点压在机械外设上**而无按键等价。
- **鼠标平滑/vsync 强制开启**：延迟黑箱，硬核社区用示波器实测并公开处刑。
