# AI 全自动开发光枪游戏：第一阶段工作流

版本：0.1 · 2026-10-04。本文是架构与实施方案，附可执行的数据预检样例；目前尚无 Godot 游戏底座、场景编译器或实机测试结果。

## 1. 核心结论

这个目标具有可落地的工程路径：先建立一个经过验证的 Godot 光枪底座、资源语义目录和关卡编译器，再让 AI 将自然语言机制要求转为规格、生成关卡、扩展机制、运行测试、读取证据并修复，最后自动交付 PC 和 Android 构建。

自动化的主体应该是**受约束的开发流水线**。模型负责理解、设计、写代码和判断修复方向；确定性的程序负责资源选择、几何组装、数据校验、场景编译、测试和打包。模型不在运行时逐帧指挥敌人，也不必每次从零写一款游戏。

最适合第一阶段的范围是：资源已备齐，定轨推进与驻点交战为主，机制可描述、可测试，场景在开发时程序化生成并保存。先证明一款短游戏能完成整个闭环，再证明换描述、换资源后可复用。

“符合要求”可以用可执行验收证明；“好玩、好看、像某部作品”仍需样片与试玩标定。可以让 AI 自动完成开发并自动筛选候选版本，但不能预先承诺任意描述、任意资源、任意设备都一次生成商业品质游戏。

## 3. 第一阶段边界与默认假设

用户已确认：**第一阶段平台输入可用鼠标模拟**。本方案据此按鼠标瞄准、左键开火、可映射装填键与测试回放设计；真实光枪、多枪驱动和实际后坐力不进入第一阶段验收。Android 可用外接鼠标或测试输入桥运行同一逻辑，触摸只是可选降级配置。

其它默认假设为 Windows PC、横屏 Android、离线单机、定轨与驻点、单人先跑通、共享屏双人接口预留。具体目标手机、风格和商业内容量尚未确定，均记为假设，不能冒充用户要求。

默认资源准备充分，仍需要一次自动化“资源入库”：模型有尺寸、轴向、连接点、碰撞、动画和行为标签，AI 才能可靠使用。资源充分不等于资源已经带有游戏语义。此处不研究建模、采购、混元 3D 或 Blender MCP；以后接入只需满足同一入库契约。

本阶段覆盖：需求编译、场景生成、镜头、波次、机制、反馈、HUD、存档、自动测试、构建、失败恢复。联网对战、商城、模型生成、商店发布不进入首个验证闭环；双人真实光枪适配留到后续硬件阶段，不能仅因留有接口而宣称支持。

## 4. 从现有调研到工程约束

**镜头与关卡（04、05）**：统一使用驻点和事件依赖图。移动完成才允许进入落位确认，确认结束才能开始敌人入场；波次结束、救援结果与分支释放必须由同一导演系统协调。不能让摄像机、刷怪器各用一个互不关联的定时器。

**输入与手感（06、14）**：每玩家独立指向状态，扳机附带同设备的瞄准快照。命中判定、可见准星、视口变换必须一致。追踪丢失与明确离屏分开。鼠标、触摸、回放和实体枪均通过相同玩法接口。

**敌人与 BOSS（07）**：前摇、伤害时刻、打断、霸体、弱点窗口写成状态机；每条危险攻击均有可记录的预告事件和可射击窗口。动画服务规则，不能由动画长短隐式改变伤害时间。

**画面与反馈（03、09、12、13）**：构图、可见性、遮挡、HUD 安全区和关键声音均进入验收。零碰撞重叠不能证明画面可读，渲染截图和音频采样不可省略。

**武器、难度、双人（08、10、11）**：资源投放依赖波次，计分规则显式化；排行榜模式固定规则与难度配置。双人命中、伤害和击杀各自可追踪，同一目标共享血量。

原文中的 0.3 秒、0.5 秒、敌人数量、章节时长等数值作为**待标定设计初值**，不视为普遍生理定律或平台保证。有些原文规则过于绝对，例如随机性一概禁止；工作流允许“固定种子、满足约束的变体”，由具体游戏需求决定。

## 5. 自动化成功的三个层次

1. **基础设施建立期**：AI 辅助实现底座、生成器、测试工具和标准资源包，首次成本最高。这个阶段不能期待只给一句话就稳定成品。
2. **已支持机制内的游戏生成**：描述被编译为数据和模块组合，自动装配、测试、修复、导出。这是最先可以稳定实现的全自动范围。
3. **新机制自动扩展**：AI 在扩展点写新代码，先证明隔离样例和回归测试，再登记到机制库。目标仍为自动完成，但失败风险、重试成本和硬件约束更高。

最终产品应返回明确状态：`PASS`（规格内证据完整）、`FAIL`（存在已证实错误）、`UNVERIFIED`（缺设备/缺渲染环境/缺需求依据）。不能因为没有报错便把后两种算成成功。

## 6. 推荐路线

从“固定镜头射击实验室”到“90 秒三驻点切片”，再到“同一资源包生成三种机制版本”，最后加入双人和批量关卡。第三步尤其关键：如果换机制仍需人工逐关摆物件，流水线还没有达到你的目标。

必须优先投入四项：资源契约、镜头与遭遇编译器、玩法底座、可观测自动试玩。聊天式 Godot 操作工具、花哨编辑器、开放世界随机地图都不是第一阶段的关键路径。
