# 13 · UI 与 HUD

> 核心规律：光枪 HUD 要回答四个问题——**准星在哪、还有几发、还能挨几下、刚才那一下值多少分**——每个答案的读取成本必须趋近于零，因为玩家的视线 90% 时间锁在准星与敌人之间。

## 1. 准星设计（核心 HUD）

- **谁渲染准星是个开关**：街机原教旨要求隐藏准星、物理指哪打哪（CRT 光枪时代传统）；依赖画面内光标定位的输入方案（屏幕追踪/指针类）需要游戏渲染准星。**默认渲染，设置里可关**（Ghost Squad 的"藏准星盲打加分"可作为高手成就继承）。渲染准星时必须**避免系统光标与游戏准星并存**——双光标既干扰瞄准又让玩家误判延迟（光标归属与屏幕裁剪细节见 `14-输入抽象与跨硬件设计.md`）。
- **准星形态**：小十字/小圆环为佳（TC 的小十字传统）；直径不大于普通敌人头部判定盒的 1/2——准星太大锁死目标，玩家失去精度感。
- **颜色双轴规则**：**玩家身份色为准星基色**（红/蓝，Point Blank 分色传统，双人必用）；**战斗状态用形状/描边表达**（空仓=虚线/开裂，可开火=实线）——两轴信息不共用颜色通道，避免双人也需状态色的冲突。
- Virtua Cop 的锁定环（绿→黄→红倒计时画在敌人身上）是画在敌人身上的第三套信息，与准星互补（`07`）。
- **命中确认在准星上**：命中瞬间准星微缩/闪白——视线所在处给反馈，玩家不需要看向敌人确认（配合 `09` 的 hit flash 双保险）。

## 2. 弹药 UI：图形化优于数字

- 弹匣图标横排（HotD 子弹图形化传统）> 数字——瞄一眼的代价趋近零，图形化在 2–3 米客厅距离下可读性碾压数字。
- 位置：屏幕下缘左/右侧（对应各自玩家），**绝不放中心**。
- 空仓状态：图形清空+准星变色+click 音三通道（`12` §3）。
- 副武器/道具栏：图标+倒计时环（`08` §2），同侧堆叠。

## 3. 生命 UI：两范式的 UI 表达

| 模型 | UI 形态 | 例 |
|---|---|---|
| 次数制 | 图标 ×N（人形/盾牌/火炬——HotD 的火炬就是命数计数器） | TC、Virtua Cop、HotD |
| 血条制 | 血条/救护包 | Umbrella Chronicles、Darkside Chronicles |

- 受击反馈：全屏边缘红闪为基础（街机通行做法）；**建议增强**：屏幕对应边缘红光/红晕指示受击方向（FPS 语汇，光枪玩家没有受击镜头反馈，方向提示可降低纯挨打感）。
- 低血量状态：全屏边缘脉动+心跳音+准星状态变化三通道，不遮挡中心。

## 4. 分数浮字与结算

- **浮字是计分规则的教学推送**（`10` §5）：+100/-200 即时浮字，位置在命中点上飘，颜色分级（正分白/金，负分红）。
- 连击计数：侧下角常驻+升级瞬间弹跳动画；combo 段位词（HotD 的 Good/Tight/Radical 式）比纯数字更有传播性。
- 结算画面分项复盘（命中率/爆头率/救援/用时/分项分）——二周目目标生成器（`10` §5）。

## 5. HUD 安全区（输入设备强约束）

部分输入方案会把识别边框叠加在画面外围，游戏有效画面被压缩（方案差异见 `14-输入抽象与跨硬件设计.md`）：
- **所有关键 HUD 向内收缩**：禁布区按输入设备特性内缩——若输入方案占用画面边缘，按其占用量并留余量预留，**做成配置项而非写死数值，用户可调**（默认量级可取画面高度约 5%）；超宽屏等特殊比例下按像素而非百分比预留。
- 四角不放点击目标与关键演出主体。
- 游戏自身不得叠加全屏边框/暗角特效盖住边缘区域。
- 提供"光枪安全区预览"设置项（叠加参考线显示安全区）。

## 6. 菜单与 UI 交互：指针即光标

- **全部菜单可用枪操作**（Wii 时代遗产，指针式输入天然支持）：准星即光标，扳机=确认。这是光枪游戏"从开机到开打不用放下枪"的体验闭环。
- 菜单目标尺寸按双距离预设设计（`06` §5）：可交互目标视角 ≥2°（桌面坐姿档 ≥1.2°）——按"屏幕高度的 5%"这类百分比在 55 寸/2.5 米下只有约 0.8° 视角，不达标，以视角制为准。
- **暂停与恢复设计**：暂停遮罩防"暂停偷瞄"；恢复后给 0.5–1 秒输入宽限（准星半透明+不可判定），避免回神瞬间误射人质——重罚落在回神误射上即成差评点。
- 加载/暂停页可做打靶小游戏（Point Blank 血统：任何等待都是靶场）。
- 校准/设备管理页：输入自检、软校准、多枪认领（目标尺寸见 `06` §5；输入方案差异见 `14-输入抽象与跨硬件设计.md`）。

## 7. 双人 UI

- 双人共享屏：HUD 左右分置、准星异色（红/蓝，Point Blank 分色传统）+ 准星带玩家编号。
- 分屏模式：分屏线绘制+各自 HUD 域（TC2 竖分线惯例）。
- drop-in 提示：P2 按 START 入席的常驻低调提示（`11` §4）。

## 8. 无障碍与舒适

- 准星大小/颜色可调（色弱模式：形状差异+颜色差异双编码）。
- 震动/血浆/镜头震动独立开关（`09` §1）。
- UI 缩放选项（客厅大屏 vs 桌面小屏）。
- 字幕规范：台词+方位提示（"[左侧] 有敌人！"可选）——单耳玩家的前摇通道补偿。

## 9. 反模式清单

- **HUD 占用屏幕中心**：准星是唯一允许占据中心的元素。
- **数字弹药在客厅距离下不可读**。
- **HUD 贴屏幕边缘**（部分输入方案的识别边框会吃掉边缘）。
- **准星过大**：精度感尽失。
- **菜单强制手柄/键盘**：放下枪=体验断裂。
- **受击无方向提示**：玩家不知道该转向哪边，纯挨打。
- **负分/惩罚无浮字**：规则黑箱（`10` 反模式联动）。
