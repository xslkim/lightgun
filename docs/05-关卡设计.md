# 05 · 关卡设计

> 核心规律：光枪关卡是"**20 分钟的身体，40 小时的灵魂**"——单局短、密度高、分支深。关卡设计的全部工作是：把 15–25 分钟的单局做爽，再用分支与模式把它变成 20 小时。

## 1. 结构金字塔

```
作品 (6–8 章)
 └ 章 (Stage)：一个场景一个主题，街机节奏 3–5 分钟
    └ 场景 (Scene/驻点群)：2–4 个波次 + 1 个小高潮，60–120 秒
       └ 波次 (Wave)：直冲型→投掷型→远程型→精英 的升温序列
          └ 单个敌人：入场语法 → 行为 → 前摇 → 攻击/被杀
```

**双时间口径（全篇统一，勿混用）**：
- 街机口径：单关 3–5 分钟，单 credit 一局 15–25 分钟（TC1 全程仅 3 关撑起 20 分钟投币链）。
- 长线游玩口径：正篇首通（含重试）1.5–3 小时；全内容（难度阶梯×分支×模式包）15–25 小时。
“6 章×3–5 分钟”描述的是街机节奏的一局，**不等于长线游玩时长**。

**驻点标准时间表（闭合模型，03/04/10 章的数字由此推导；区间为设计目标，非算术推导）**：
落位确认 0.5 秒（禁刷敌）→ 每波 8–20 秒 × 2–4 波 → 波间喘息 1–2 秒 → 驻点合计 20–45 秒 → 场景（2–4 驻点）= 60–120 秒，内含 1–2 个 checkpoint（checkpoint 粒度 60–90 秒，见 §4）。

街机基准数据（正典平均值）：
- 首关必须在 **30–90 秒内给足命中爽感**——这是“锁住玩家”的街机遗产，非投币语境下同样是留存与口碑的第一屏。
- 章尾 BOSS；章内至少一个"小高潮"（尸潮/巨物/场景杀）。

## 2. 波次编排：升温序列与密度控制

**规则**：
1. 波内敌人按威胁响应时间排序：**直冲型（逼瞄速）→ 投掷型（逼预判）→ 远程型（逼优先级）→ 精英（逼部位）**。随机混排只在高手段关卡用。
2. 密度参考：屏幕同时在场敌人 2–4 只（普通）、5–8 只（尸潮景观波）、1 只（BOSS/精英决斗）。**密度不是难度首选旋钮**（见 `10-难度曲线与计分.md`：难度上限优先用变奏而非密度，反应窗有 0.3 秒生理下限）。
3. 波与波之间留 1–2 秒"捡弹/喘息"窗；尸潮波前必给弹药或人质奖励。
4. 屏幕外入场必配声音预告+固定入场语法（见 04）。

**实例**：HotD2 第一章开局 30 秒内：两只直冲僵尸→救平民事件→三连破窗僵尸——教科书式的"直冲→事件→密度"三拍。

## 3. 分支系统：重玩性的发动机

### 3.1 三类触发器
| 类型 | 机制 | 代表 |
|---|---|---|
| **平民存活状态** | 救成走正路/失败绕险路 | HotD1（1F 救到人走 3F 近路，失败遇 Hangedman）、HotD2 全章 |
| **特定击破/效率** | 打爆路障/牌子的时机决定路线 | VC2 路牌选路、HotD 打爆特定物体换路 |
| **裸选择** | 门口/路径直接选 | Ghost Squad 射门牌选路、HotD 开门左右 |

### 3.2 分支设计规则
1. **分支必须可感知**：选了路但战斗同质=玩家发现不了=白做。分支不只是"路径不同"，应是**敌人谱系+演出+BOSS 前菜**整体换血。
2. **情节中性原则**：HotD 的分支"换路不换故事"——分支控制移植成本，主线结局另有触发。小团队首选此模型：路径分支影响玩法与奖励，不影响主叙事；叙事分支留给结局层（HotD3 四结局）。
3. **一周目看得见、二周目够得着**：分支后果要"看得见摸不着"（看到隔壁路线的入口/听到声音），制造二刷目标。
4. **分支密度参考**：HotD2 每章 2–4 个决策点、8 种路线模板；Ghost Squad 单流程约 24 种任务变体（含事件组合）+16 级难度=参数化重玩性（见 §5）。

## 4. Checkpoint 与节奏钩子（街机遗产的翻译）

街机语法：死亡→倒计时 10 秒→投币→**场景级 checkpoint 复活**，分数清零。续关倒计时演出本身是节奏部件。

长线单机游玩翻译：
- checkpoint 粒度保持**场景级**（≈每 60–90 秒一个），死亡重启成本低到不砸手柄。
- **钩子点设计**保留：街机把壮观场面放在普通玩家"续关之后"（投币动机）；长线语境把爽点放在“死亡重生之后”——玩家刚死，重生后 10 秒内给一个易得的小高潮，缓解挫败。
- 章节开头允许直接从 checkpoint 进入（现代玩家的最后底线）。

## 5. 长线游玩内容模型：从 3 小时到 20 小时

街机短会话→长线内容的五种扩容手法（1997–2010 验证集），长线单机作品直接可用：

| 手法 | 内容 | 代表 |
|---|---|---|
| **模式包** | Original 模式（积分买开局）、BOSS Rush、训练模式（速度/精度靶场）、Time Attack、Extreme | HotD2(DC)、HotD 2&3 Return |
| **剧情/新章节** | 追加后日谈、新产线 | TC PS1 的 Kantaris Deal、Umbrella Chronicles 的 Umbrella's End |
| **参数化难度** | 同一内容 × N 级难度阶梯 × 分支决策 | Ghost Squad 16 级、3 任务×24 变体 |
| **解锁层** | 武器库、服装、隐藏枪、作弊项 | Ghost Squad、Confidential Mission |
| **UGC 编辑器** | 波次/靶场编辑器+内容分享——把内容寿命从开发产能交给玩家社区的长线武器；可承诺+后续交付（公开路线图本身就是内容承诺） | Big Buck 内容日历的独立团队替代方案 |

> 成本注记：双人刷怪表、每敌型 ×2 皮肤/动作变体、HUD 双域、分支场景整体换血——这些"×2"系数要写进工作量估算，否则上述配方估算会系统性偏乐观。

**现代推荐配方**（小团队产能友好）：
> 主线 6 章（街机节奏 20–30 分钟；含重试首通约 1.5–2.5 小时）+ 分支变体（×3 路线）+ **3–5 档精调难度**（系统容量可扩至 Ghost Squad 式 16 级，但 16 级是容量上限不是调参工作量——交付目标是 3–5 档精调+隐性变奏）+ 靶场训练模式（兼新手教学+精准度自检，规格见 `10` §8）+ BOSS Rush + 排行榜速通层 ≈ 首通 1.5–2.5 小时 / 全内容 15–25 小时。

成本效率排序：**参数化（难度/变异规则）> 模式包 > 分支 > 新章节 > UGC**。Ghost Squad 是"短内容×深系统"的最直接参照。

**内容量自检**：内容量与玩家时间投入预期必须一起立项（警惕 HotD Remake 式“预期-内容量落差”差评）。首通 <1.5 小时且全内容 <10 小时的项目，需以 UGC/更新路线图补足长线内容承诺，或按短会话街机口径重新校准设计目标。

## 6. 关卡模板库（供量产复用）

| 模板 | 结构 | 代表场景 |
|---|---|---|
| 巡逻推进 | 巡航轨+持续低密度+2 高潮波 | VC 城市巡逻、HotD 街道 |
| 驻点攻防 | 驻点×3–5，波次升温，尾波精英 | TC 系、Ghost Squad |
| 护送/护航 | 平民/搭档=会动的计时器，路线分支多 | Operation Thunderbolt、HotD 救援段 |
| 追逐 | 强制推进+身后威胁+QTE 逃脱 | HotD4 逃脱段、Elevator 段 |
| 巨物战 | 单 BOSS 多阶段+场景互动 | Ocean Hunter、Lost World |
| 靶场间章 | Gallery 形态调剂，教学新机制 | HotD 打靶段、Ghost Squad 靶场 |
| 多屏驻点 | 枪口指向=镜头转移 | TC4 Multi-Screen、TC5 左右探头 |

**规则**：每章由 2–3 种模板拼接；同模板不得连续出现超过两章；章间用模板对比制造节奏记忆（追逐→驻点→巨物）。

## 7. 关卡自检清单

- [ ] 首关 90 秒内有命中爽感高潮？
- [ ] 每个驻点三问有答案（打谁/从哪来/打完去哪）？
- [ ] 波次升温序列成立（无随机混排的普通段）？
- [ ] 每章 ≥1 个可剪辑名场面？
- [ ] 分支可感知（换了路玩家 10 秒内能发现）？
- [ ] checkpoint 场景级、重生后 10 秒内有小高潮？
- [ ] 通关时长的内容量支撑（模式包/难度阶梯/分支/UGC 路线图）？内容量与时长口径是否自洽？
- [ ] 同模板不连续超过两章？

## 8. 反模式清单

- **内容量直搬街机**：长线语境只给 3 小时街机内容量（HotD 2&3 Return 被批“移植完美但几乎无新增”，MC 66）。
- **分支不可感知**：见 §3.2。
- **难度靠密度硬顶**：反应窗有生理下限，密度超标=抽签。
- **checkpoint 过粗**：死亡回退超过 90 秒=现代差评引擎。
- **无间章调剂**：全程高强度无呼吸段，30 分钟后玩家疲劳流失。
- **把"多结局"当内容量**：只有结局贴图不同、gameplay 无差的分支是伪重玩性（HotD 的结局梗虽是文化符号，但真正驱动重玩的是 gameplay 分支——两种都要）。
