# 02 · 世界观与题材

> 核心规律：**题材即机制包**。光枪游戏选题材不是选皮，而是选一组自带机制。选定题材后应全盘接受其机制包，错嫁必翻车。

## 1. 五大题材及其机制包

| 题材 | 自带机制 | 打击反馈合法化 | 代表 |
|---|---|---|---|
| **丧尸恐怖** | 惊吓点(jump scare)、屏幕外破入、人质哀嚎、尸体复活的规则简单性 | 爆浆级反馈、断肢、血浆 | HotD 全系、Overkill、Extraction、Beast Busters |
| **军警特勤** | 掩体节奏器、机枪压制、计时任务、平民纪律 | 弹孔、布料、爆炸 | Time Crisis、Virtua Cop、Ghost Squad、Operation Wolf |
| **怪兽冒险喜剧** | 巨物BOSS连战、场景互动杀、情侣/家庭双人 | 大体型受击、部位剥落 | Let's Go Jungle/Island、Ocean Hunter、Lost World |
| **科幻/飞行** | lock-on、预判弹幕、巨型舞台、无敌动画期 | 能量爆散、机甲破坏 | Panzer Dragoon、Star Fox、L.A. Machineguns |
| **狩猎/嘉年华** | 规则极简（打公鹿不打母鹿）、微游戏拆分、奖票/比分 | 数字化弹着、即时奖惩 | Big Buck Hunter、Point Blank、Wild Gunman |
| （交叉）**B级片/黑色** | 风格化叙事、脏话与梗、导演剪辑 | 风格滤镜下的夸张反馈 | Overkill、Typing of the Dead |

**规则**：
- 选题材 = 同时选定：可射击对象伦理（人类出现即必须引入勿射规则）、反馈尺度（恐怖可爆浆、警匪只能布料弹孔）、教学成本（IP/恐怖题材观众自带认知，原创题材要自己教）。
- **题材-机制错嫁是反模式**：嘉年华题材硬上掩体三态=不适配；恐怖题材不上惊吓点位=浪费题材溢价；写实警匪硬上爆浆=反馈失真。

## 2. 世界观构建法：表层简单 + 暗线考古

30 年来最成功的光枪世界观遵循同一个公式：

> **5 秒能讲清的表层任务 + 一条"打了 20 年才发现"的暗线。**

- **表层**：一页纸设定。HotD："特务机关 AMS 探员进庄园救人打僵尸"；Time Crisis："特勤 VSS 探员救被绑架的女友/阻止政变"；Ghost Squad："特种小队突袭解救人质"。角色即玩家化身，**低个性高代入**——主角基本不说话，因为玩家在说话（用枪）。
- **暗线**：世界观藏在文件、台词、结局分支里。HotD 的 DBR 公司阴谋、Curien 与 Goldman 的传承、塔罗牌 BOSS 命名体系——B 站"死亡之屋世界观介绍" 84.5 万播放、3.7 万赞，"玩了20多年才知道讲了什么故事"式视频成系列。**暗线是留给社区考古的长线话题资产**（见 `12-音频与配音.md` 的传播设计）。
- **组织架构**：用一个虚构机构承载系列（AMS、VSS、Umbrella），机构=续作资产+敌人谱系容器。

**规则**：
1. 世界观文档里最该写清楚的是：**为什么是"你一个人（或两个人）"在打**——定轨射手的孤立感必须有叙事解释（探员/先遣队/幸存者），否则玩家会问"军队呢？"。
2. 敌人来源一句话讲清（病毒/组织/异星/幽灵），因为敌人刷新的"无穷无尽"需要合法性。
3. 场景流转要有任务逻辑（庄园→沼泽→工厂），但允许街机式的"理由跳关"——玩家接受"追凶追到游乐园"，因为每关开头有任务简报。

## 3. 各题材执行规范

### 3.1 丧尸恐怖
- 恐怖的三个时间点：**逼近时**（慢速逼近+哀嚎声源定位）、**入场时**（屏幕外破窗/破门+音刺，惊吓点）、**爆发时**（尸潮景观）。
- 惊吓点是时间轴资产：推进段埋设"假动作"（猫跳 scare，虚惊）与真威胁共用同一入场语法，让玩家永远无法建立安全感。
- 恐怖豁免权：恐怖题材让"敌人打不疼、倒下又爬起、爆浆断肢"全部合法——反馈尺度可以拉满。
- 语音允许"坏"：B级片美学是风格选择（见 `12-音频与配音.md`），但现代作品应**自觉的 B 级**而非无意的不堪。

### 3.2 军警特勤
- 掩体/踏板机制的家（见 `06-操作与手感.md`）。计时任务、人质、拆弹等"程序正义"演出是题材红利。
- 勿射平民在警匪题材里有天然的合理性背书（Lethal Enforcers 粉衣平民、Virtua Cop 人质）。
- 军事题材注意：写实现代军事容易撞上审查与审美疲劳，Ghost Squad 的"架空特勤+面具敌人"是更耐用的解法。

### 3.3 怪兽冒险喜剧
- 巨物 BOSS 是主菜：体型即奇观，一次遭遇一个记忆点（Let's Go Jungle 的巨型昆虫、Ocean Hunter 的七大洋巨兽）。
- 喜剧基调降低挫败：失败时角色出糗而非死亡演出，适合情侣/家庭双打（Let's Go 系列的情侣双人定位是街机厅验证过的）。
- 文化语境注意：怪兽冒险是**文化门槛最低**的题材（跨文化共鸣强），且国产街机新机台（海盗传说、飞龙在天、猎魔1892）已验证双人水枪/枪机路线在中文玩家群体中的热度。

### 3.4 狩猎/嘉年华
- 规则一句话讲清是生死线：Big Buck"打公鹿、误击母鹿即死"是奖票机最简纪律计分。
- 微游戏化（Point Blank）：单个挑战 3–10 秒、规则即到即会、失败成本趋零——这是最好的新手漏斗与派对模式骨架。
- 非暴力=合家欢通行证（全年龄友好、内容分级宽松），但狩猎题材需做文化敏感度评估。

## 4. 中文玩家群体的情感锚点（社区调研结论）

做面向中文玩家的光枪游戏，这些是被 B 站高赞反复验证的"对味点"：

1. **机厅记忆内核**：双人抢枪打僵尸、"围观者以为弱鸡，原来是过江龙"的一币通关炫耀、"偷家里10块钱打一下午"。→ 双人同屏 + 街机式成绩炫耀系统（本地排行、速通计时）直接对位这种情感。
2. **渣配音梗化**：HotD 的生硬配音+夸张惨叫已成品类独有资产（全语音视频 59.5 万播放）。→ 新作品可以自觉设计"可梗化"台词与名场面（BOSS 台词、死亡语音）；**中文字幕与成就名本地化必做，中文配音按 `12` §4 决策树分级**（以中文玩家为主要受众的风格化题材优先，写实向宁缺毋滥）——社区会自己汉化，官方缺位等于放弃传播。
3. **剧情考古需求**："打过但没看懂"是集体记忆。→ 留暗线、留可考古的世界观文件，主动做"剧情向"可剪辑内容（BOSS 图鉴、人物志）。
4. **"云通关"遗憾补偿**：大量玩家童年没通关，靠看视频完成心愿。→ 非投币语境下给一个“终于能通关”的合理难度曲线，是直接踩在情感需求上的设计。
5. **"吞金兽"反面记忆**：机台贵、吃币快、维护差。→ 非投币语境下难度必须给足正反馈（见 `10-难度曲线与计分.md`），让“当年没通关的，这次终于打完”成为可兑现的设计承诺。

## 5. 反模式清单

- **题材与机制错嫁**（见第 1 节）。
- **写实演出陷阱**：光枪的演出上限被交互深度锁死，写实 CG 永远比不过同时代电影，而风格化（哪怕自嘲）把"假"重新定义为趣味。Overkill 用 Grindhouse 美学成为第一卖点；写实 B 级预算两头不讨好。
- **世界观过载**：开场 10 分钟播片讲设定。街机语法的遗产是"30 秒简报+直接开打"，过载的世界观应该在收集品与分支里展开。
- **无机构无传承**：纯一次性世界观放弃系列化资产；机构+敌人谱系+命名体系（塔罗牌/代号）是低成本高识别的世界观骨架。
- **Duck Hunt 式道德真空照搬**：现代作品出现“打人类敌人”必须给勿射规则或非人类敌人设定，否则内容分级与舆论双风险（Lethal Enforcers 曾因暴力争议在德国被禁——教训是分级意识前置）。
